# Novogradnja Zadar

Portal za izlistavanje novih stanova za prodaju u Zadru. Prva verzija je jedna statična stranica (`index.html`) s primjerima podataka.

## Pokretanje

Otvorite `index.html` u pregledniku. Nije potreban build.

## Napomena

Projekti, investitori i cijene su izmišljeni primjeri. Obrazac za upit još ne šalje poruke.
